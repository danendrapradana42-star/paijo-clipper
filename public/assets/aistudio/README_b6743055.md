# Auto Clipper Desktop

Versi desktop Windows berbasis Electron. Aplikasi berjalan di jendela sendiri dan membawa Chromium; browser terpisah tidak diperlukan. Audio/video pengguna tetap diproses di perangkat. Whisper dan MediaPipe masih memerlukan internet saat pertama kali mengunduh aset/model.

## Jalankan untuk pengembangan

1. Pasang Node.js 24 atau lebih baru.
2. Buka terminal di folder `desktop-app`.
3. Jalankan `npm install` lalu `npm start`.

`main.js` mengelola jendela desktop. `whisper-local/server.js` menyajikan UI melalui localhost dengan header cross-origin isolation yang diperlukan Whisper WASM. UI dan fitur clipper ada di `Auto-Vertical-Fix.html`.

Sesudah memilih video, tentukan model, bahasa, dan target minimal jumlah klip, lalu klik **Buat subtitle otomatis**. Model multilingual mendukung banyak bahasa; model berlabel English hanya untuk audio bahasa Inggris. Model Small Q5 sekitar 182 MB dan memakai lebih banyak memori. Jika model sudah mulai dimuat, menggantinya memerlukan membuka ulang aplikasi.

Kalau video sudah memiliki subtitle, klik **Pilih subtitle (opsional)** dan pilih file `.srt` atau `.vtt` sebelum memilih video. Aplikasi melewati transkripsi Whisper dan langsung mencari momen klip; subtitle tetap bisa diperbaiki dari panel subtitle.

## Pipeline Video AI

Bagian **Video AI Otomatis** menyediakan durasi minimal **10 menit** (40 adegan) atau **15 menit** (60 adegan), sekitar 15 detik per adegan, channel Kreasi Animasi/Motion Makers, dan jenis konten edukasi umum, bisnis/ekonomi, manusia purba/sejarah, serta POV. Naskah ditargetkan sedikitnya 120 kata per menit dan sistem menolak naskah yang kurang dari jumlah adegan atau kata minimum tersebut. Timeline video menjaga durasi minimum yang dipilih. Aturan kreatifnya mencakup kehati-hatian fakta, satu ilustrasi vertikal doodle per adegan, konsistensi karakter, dan tanpa teks/logo pada gambar.

- Teks naskah dan prompt gambar dikirim ke Google Gemini API hanya setelah pengguna menjalankan tahapnya. Video, audio, subtitle, dan model Whisper tidak dikirim ke Google. Siapkan API key di Google AI Studio, lalu simpan lewat panel Koneksi AI & Suara; aplikasi menyimpan kunci dengan enkripsi Windows.
- Untuk Google Flow, tombol **Login / Buka Google Flow di Browser** membuka situs resmi di browser bawaan komputer. Login dilakukan langsung di Google; Auto Clipper tidak membaca kata sandi atau sesi browser.
- Pilih **Google Flow · buat manual di browser**, siapkan adegan, lalu untuk tiap adegan salin prompt dan buka Flow. Buat gambar di Flow, unduh ke komputer, lalu impor ke kartu adegan yang sama. Semua gambar Flow harus diimpor sebelum render video.
- Gemini API langsung dan ilustrasi lokal tetap menjadi pilihan lain. Pembuatan naskah dan gambar Gemini memerlukan API key, yang disimpan terenkripsi Windows.
- Suara memakai VoiceStudio yang berjalan lokal di `http://127.0.0.1:3900`. Pilih sampel, dengarkan preview, lalu centang pernyataan izin sebelum menekan **Buat Profil di VoiceStudio**. Profil yang sudah ada juga dimuat dari VoiceStudio.
- Empat MP3 contoh ikut dalam folder `voices/`. Membuat profil mengirim sampel pilihan ke VoiceStudio lokal saja; teks narasi diproses melalui API lokal VoiceStudio.

Google Flow tidak terhubung otomatis ke Auto Clipper: login dan pembuatan gambar berlangsung di browser, lalu pengguna mengimpor hasilnya. Login Google tidak menggantikan API key Gemini untuk membuat naskah. Tanpa VoiceStudio, pembuatan suara dapat dilewati dan pengguna masih dapat merekam narasi lewat mikrofon. Pembuatan dan impor gambar untuk 40–60 adegan memerlukan waktu.

## Cara cepat menjalankan

Ekstrak ZIP, lalu klik dua kali `Jalankan-Auto-Clipper.bat`. Saat pertama kali dijalankan, skrip memasang Electron lewat npm jika belum ada, lalu membuka aplikasi desktop. Pastikan Node.js dan npm sudah terpasang serta internet aktif saat pemasangan pertama.

## Buat installer

Jalankan `npm run build:windows` atau PowerShell `scripts\Build-Installer.ps1`. Skrip mengunduh Electron resmi versi yang ditetapkan, menyalin proyek ke `resources\app`, lalu membuat `dist\Auto-Clipper-Setup.exe` dengan IExpress Windows. Installer memasang aplikasi di `%LOCALAPPDATA%\Programs\Auto Clipper` dan membuat shortcut Desktop/Start Menu. Isi proyek ini adalah kode sumber yang bisa diedit sebelum build.

Jika ingin menguji perubahan tanpa membuat installer, jalankan `npm start`.
